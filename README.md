# Auto Deafen
I created autodeafen for macOS and Windows because there are currently no reliable options for macOS, and support for Windows is easy.
## macOS
To install this mod on macOS, you must download the mod from: https://github.com/dreead/AutoDeafen/releases/latest/ and put it in "~/Geometry Dash/Contents/geode/mods", to find your Geometry Dash installation, go to steam and right click on Geometry Dash and hover on  Manage and press "Browse local files". Once you press that, right click on the icon for Geometry Dash and press Show Package Contents. The rest is self explanatory.
## Windows
Installation on Windows is similar; to install this mod on Windows, you must download the mod from: https://github.com/dreead/AutoDeafen/releases/latest/ and do the same in steam and go to geode and mods.
