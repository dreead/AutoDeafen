# Auto Deafen
I created Auto Deafen for macOS and Windows because there are currently no reliable options for macOS, and support for Windows is easy.
## macOS
To install this mod on macOS, you must download the mod from: https://github.com/dreead/AutoDeafen/releases/latest/ and put it in "~/Geometry Dash/Contents/geode/mods", to find your Geometry Dash installation, go to steam and right click on Geometry Dash and hover on  Manage and press "Browse local files". Once you press that, right click on the icon for Geometry Dash and press Show Package Contents. The rest is self explanatory. Once this is installed, go to System Settings (System Preferences on earlier versions of macOS)->Privacy and Security->Accessibility->Press +-> Point it to your GD installation and click open. **This is required for the mod to work.** Your settings should look something  like this.

## Windows
Installation on Windows is similar; to install this mod on Windows, you must download the mod from: https://github.com/dreead/AutoDeafen/releases/latest/ and do the same in steam and go to geode and mods.
